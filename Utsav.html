Projects

03

GLITCH

MSc dissertation · Sep 2026

Adaptive game AI under runtime instability — Unity 6, C#

A third-person shooter built as a controlled experiment. Thirty enemy agents run in every session: fifteen driven by a finite state machine, fifteen by utility scoring. Same models, same weapons, same navigation — the only difference is how they choose what to do next.

Five scripted failures then break the world mid-match: gravity inverts, walls stop existing, enemies duplicate, time stutters, and a second player appears. A C# telemetry logger records thirteen behavioural fields per agent every second to CSV, which I analyse in Python.

Partway through I found the utility scorer had no patrol action, so attacking won by default and the results were meaningless. Rebuilding the action set and the line-of-sight gating, then re-running the full experiment, is the part of this project I learned the most from.
